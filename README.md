# Health Insurance Price Prediction

## 📌 Project Overview
The **Health Insurance Price Prediction** project uses machine learning regression algorithms to predict health insurance charges based on customer information and relevant features.

## 🎯 Objectives
- Analyze health insurance data and identify important factors affecting insurance charges.
- Perform data cleaning and exploratory data analysis (EDA).
- Train and compare multiple machine learning regression models.
- Evaluate model performance to identify a suitable prediction model.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost
- **Model Serialization:** Pickle

## 🤖 Machine Learning Algorithms
The following regression algorithms are used for model training and comparison:

1. Linear Regression
2. K-Nearest Neighbors (KNN) Regressor
3. Decision Tree Regressor
4. Random Forest Regressor
5. Gradient Boosting Regressor
6. XGBoost Regressor
7. Support Vector Regression (SVR)

## 📊 Project Workflow

1. Load the dataset.
2. Explore and understand the data.
3. Clean and preprocess the data.
4. Perform exploratory data analysis and visualization.
5. Split the dataset into training and testing sets.
6. Train multiple regression models.
7. Evaluate and compare model performance.
8. Select a suitable model for predicting insurance charges.

## 📈 Model Evaluation
Regression models can be evaluated using:

- **MAE:** Mean Absolute Error
- **MSE:** Mean Squared Error
- **RMSE:** Root Mean Squared Error
- **R² Score:** Measures how well the model explains variation in insurance charges.

The best model should be selected based on actual evaluation results.
